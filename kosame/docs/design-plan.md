# 디자인 플랜 — 카페 코사메(小雨)

## 한 줄 콘셉트
**"가랑비 오는 저녁, 골목 안 찻집에 도착하기까지의 기승전결(起承転結)."**
기승전결은 원래 한·중·일이 공유하는 서사 구조이고, 일본식 찻집이라는 주제와 직접 맞닿아 있습니다. 그래서 장(章) 표시를 숫자(01/02…) 대신 실제 순서를 뜻하는 한자 `起 承 転 結`로, 세로쓰기 레일에 둡니다.

## 컬러 (빗속의 저녁 골목)

|---|---|---|
| 안개 mist | `#E7EBEA` | 기본 배경 — 차가운 회녹색, 크림색 배경을 의도적으로 피함 |

| 등불 lamp | `#D9A04E` | 영업 중 표시 점, 빗줄기 하이라이트 — 장식에만, 글자에는 쓰지 않음 |
| 밤 night | `#17242A` | 히어로·마무리 장 배경 |

## 타이포그래피
- 본문: 한국어 Noto Sans KR, 일본어 Noto Sans JP, 영어 Inter (가이드라인 대안 폰트, 모두 OFL)
  - Pretendard는 이 작업 환경에서 내려받을 수 없어 가이드라인의 대안인 Noto Sans KR을 사용 (검토 로그 참고)
- 제목·한자 표시: Noto Serif CJK(명조) — 일본 찻집의 차림표(お品書き) 같은 인상. 본문 가독성 규칙은 그대로 유지
- 모든 폰트는 페이지에 실제 쓰인 글자만 남긴 woff2 서브셋으로 직접 호스팅

## 레이아웃
```
[히어로 — 밤, 빗방울 맺힌 창]
|                                   小 |   ← 세로쓰기 명조, 오른쪽
|                                   雨 |
| 인천 구월동, 카페 코사메               |
| 가랑비 같은 하루,                     |
| 골목 안 작은 찻집에서                  |
| [● 지금 영업 중]  [길 찾기]            |

[起] 레일 | 본문 34rem (왼쪽 정렬)         | 세로 사진
[承] 레일 | 차림표: 점선 리더 + 가격        | 사진 2장 엇갈림
         | 계절 당고 — 가로 와이드 사진
[転] 레일 | 큰 인용 "당고 좋아하세요?"      | 사진
         | 플랫폼 기록 3개 / 국내·해외 목소리 / 알고 가면 좋은 점
[結] 밤 배경 + 골목 사진 | 방문 정보 표 | 지도 앱 3종 | FAQ | 마지막 CTA
```
- 텍스트는 왼쪽 정렬, 한 줄 35~40자(한·일) / 60~70자(영)
- 모바일: 레일이 제목 위 가로 한 줄(큰 한자 + 작은 라벨)로 바뀜

## 원칙
1. 대담함은 한 곳에만: 히어로의 세로 `小雨`와 아주 옅은 빗줄기. 나머지는 조용하게.
2. 움직임은 한 번: 히어로 진입 시퀀스. 그 외에는 장 표시 한자가 먹이 번지듯 나타나는 것 하나뿐. `prefers-reduced-motion`이면 모두 끔.
3. 카드 키트 금지: 메뉴는 카드가 아니라 찻집 차림표처럼 점선 리더로.
4. 사실만: 후기는 요약해 출처와 함께, 단점도 함께 보여줌. 사진은 분위기 이미지임을 명시.

## 계획 재검토 (브리프 대비)
- 처음 떠올린 안: 따뜻한 크림 배경 + 명조 제목 + 갈색 강조 → 일반적인 "감성 카페" 기본값이라 폐기. 이름(가랑비)에서 출발해 차가운 안개색과 쪽빛으로 바꿈.
- 섹션 번호 01~04 → 내용이 실제 순서이긴 하지만 기승전결 한자가 더 구체적이라 교체.
- 숫자 카운트업 → 리뷰 수가 작아(54개) 과장으로 보일 수 있어 제외.
