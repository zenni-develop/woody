## 2차 검토 — 접근성(WCAG 2.1 AA) + 보안 + 성능

사용 스킬: `accessibility-review`
방법: 자동 점검 스크립트(대체 텍스트, 제목 구조, 랜드마크, 링크 이름, 터치 영역, 탭 순서, 200% 확대·320px 폭 가로 넘침), 대비 계산, 다크 모드 캡처

| 1 | 상단 내비 랜드마크 이름이 "이야기"로 잘못 붙음 | 4.1.2 | 🟡 | 언어별 "페이지 안내 / ページ内の移動 / On this page" |
| 2 | 상단·하단 언어 메뉴의 랜드마크 이름이 같음 | 1.3.1 | 🟢 | 하단은 "(하단)"으로 구분 |
| 3 | 건너뛰기 링크가 히어로의 길 찾기 버튼까지 건너뜀 | 2.4.1 | 🟡 | 본문 시작(main)으로 이동하도록 변경 |

### 점검 결과 요약
- 대체 텍스트 누락 0, `h1` 페이지당 1개, 링크 이름 누락 0, 새 창 링크 `noopener` 누락 0
- 320px 폭, 200% 확대(640px)에서 가로 넘침 없음, 콘솔 오류 없음 (3개 언어 + 언어 선택 페이지)
- `prefers-reduced-motion`에서 히어로 시퀀스·빗줄기·한자 번짐 효과 모두 정지
- (2차 당시) 다크 모드에서 모든 텍스트 대비 7:1 이상 — 3차에서 다크 모드는 제외

### 보안 점검
- **CSP**(메타 태그): 스크립트·스타일·폰트는 자기 사이트만, 이미지는 자기 사이트 + `images.unsplash.com`만 허용. 인라인 스크립트·인라인 스타일 0개, `form-action 'none'`, `object-src 'none'`
- 외부 스크립트·외부 폰트·분석 도구 0개 (폰트는 직접 호스팅)
- 모든 외부 링크 `rel="noopener noreferrer"`, `Referrer-Policy: strict-origin-when-cross-origin`
- 개인정보: 리뷰어 이름 미노출(요약만), 개인 휴대전화 번호 미게재, 입력 폼 없음
- 빌드 의존성 0개(npm 패키지 없음) → 공급망 위험 없음
- GitHub Actions: `contents: read`, `pages: write`, `id-token: write`만 부여
- 한계: GitHub Pages는 HTTP 응답 헤더를 직접 설정할 수 없어 `frame-ancestors`(클릭재킹 방지)를 적용할 수 없음. 입력·결제 기능이 없어 위험은 낮음. 필요하면 Cloudflare 등 앞단에서 헤더 추가
- 한계: 사진을 Unsplash에서 직접 불러오므로 방문자 IP가 Unsplash에 전달됨. 실제 매장 사진으로 교체할 때 `public/images/`에 직접 호스팅 권장

### 성능 (참고 수치)
- 페이지 HTML 약 25KB, CSS 약 22KB, JS 약 5KB
- 폰트(언어별 해당 언어만 로드): 한국어 약 95KB, 일본어 약 257KB, 영어 약 39KB
- 사진: Unsplash CDN에서 화면 폭에 맞는 크기(640~2000px)와 최적 포맷(auto=format)으로 제공, 첫 화면 외에는 지연 로딩

## 3차 업데이트 — 밝고 화사한 톤 (사용자 피드백)

피드백: 메인 사진이 어두운 밤이라 낮 영업시간과 맞지 않음, 식물이 있는 식물원 같은 분위기, 전체적으로 밝고 화사하게.

| 변경 | 내용 |
|---|---|
| 사진 7장 중 6장 교체 | 밤 창가·어두운 골목 → 유리 지붕 아래 식물 카페, 햇살 드는 창가 화분, 비 오는 바깥이 보이는 밝은 창가 등 낮 사진 |
| 팔레트 | 쪽빛·밤 배경 → 잎빛 종이, 세이지, 블러시, 민트 + 말차 잎 강조색 |
| 히어로·結·푸터 | 어두운 면 → 밝은 면, 글자는 짙은 초록 |
| 문구 | "가랑비 같은 하루" → "가랑비 그친 오후, 골목 안 초록 찻집에서", 공간 설명에 초록 식물·대나무 발 추가(다이닝코드 후기 근거), 마무리 문구를 낮 시간에 맞게 |
| 다크 모드 | 밝은 화면 요청에 맞춰 제외 |

재점검: 3개 언어 + 언어 선택 페이지에서 대체 텍스트 누락 0, 44px 미만 터치 영역 0, 320px·200% 확대 가로 넘침 없음, 콘솔 오류 없음, 포커스 표시 대비 12.7:1.
글자 대비: 본문 12.7:1, 보조 6.7:1(세이지 면 6.0:1, 블러시 면 5.9:1), 강조색 6.0:1(세이지 5.4:1).

## 4차 업데이트 — 메뉴·언어별 링크 점검 (사용자 피드백)

방법: GitHub Pages와 같은 `/woody/` 경로로 띄운 뒤 3개 언어 × 데스크톱(1440px)·휴대폰(390px)에서 모든 링크를 실제로 클릭해 이동 위치와 응답 코드 확인. 압축을 풀어 파일로 직접 연 경우도 확인.

| 발견 | 반영 |
|---|---|
| 휴대폰·태블릿(900px 미만)에서 이야기·메뉴·방문 안내 링크가 숨겨져 있었음 | 로고 아래 한 줄로 항상 보이도록 추가 (터치 영역 44px) |
| 언어 전환 링크가 `../ja/` 폴더 주소라 파일로 열면 폴더 목록이 뜸 | `../ja/index.html`로 변경 — 서버·로컬 모두 정상 |
| "방문 안내"를 누르면 제목 대신 위쪽 사진에 멈춤 | 이동 지점을 제목으로 옮김 |
| 지금 읽는 장이 메뉴에 표시되지 않음 | 현재 장의 메뉴 항목을 초록 밑줄로 표시 |
| 언어를 바꾸면 맨 위로 돌아감 | 보던 장(이야기·메뉴·방문 안내)을 유지한 채 다른 언어로 이동 |

결과: 메뉴 3개 × 언어 3개 × 화면 2종 모두 해당 장 제목이 상단 바 바로 아래에 보임. 언어 링크 9개, 언어 선택 페이지 3개 모두 200 응답. 외부 링크(지도·인스타그램·출처·사진 작가)는 언어별로 올바르게 연결되며 모두 새 창으로 열림. 한국어 길 찾기는 네이버 지도, 일본어·영어는 구글 지도로 연결.
